Markowitz Portfolio Optimization

Mean-variance optimization across 13 stocks — building the covariance matrix, inverting it, and benchmarking the result against the market.

Σ

What it is

A full mean-variance analysis in the Markowitz tradition: find the portfolio that maximizes risk-adjusted return across a 13-stock universe, then check honestly whether it actually beat just holding the market.

What I built

  • Solved the tangent (max-Sharpe) portfolio across 13 stocks with mean-variance optimization — building the full covariance matrix and inverting it to derive the optimal weights.
  • Ran a CAPM single-index regression on every stock for beta, Jensen's alpha, R², and firm-specific risk, with complete ANOVA output (t-stats, p-values, 95% CIs).
  • Benchmarked risk-adjusted performance — annualized Sharpe, M², information ratio, and tracking error — against the SPY market index.
  • Built a Treynor-Black Single Index Model portfolio and a $1,000 allocation.

Result

Both the Treynor-Black portfolio and the tangent portfolio beat the market, with annualized Sharpe ratios above 1.18.
